Effects Container — Two Proposals · Black tint medium baseline

Proposal A — Triple-tone Banding

Each effect is a self-contained block led by a coloured pill carrying the trigger label. Four tones partition the categories: violet for Persistent Modifiers (rule, not behaviour), amber for Passives, cool blue for reactive triggers (On Reveal / Enter / Leave / Complete), ember red for active triggers (Action / Character Phase / On Flow Marker). Conditionals are extracted as a violet while-clause with a left rule, sitting between pill and body. Effects are separated by an ornamented hairline rule.

Proposal B — Left Rail Accent

Each effect is keyed by a vertical colour rail at its left edge — same four-tone palette as Proposal A. The trigger label sits inline with any conditional clause, both in the rail's tint, so the head reads as a single statement: label · ⟨while …⟩. Effects separate purely by vertical gap; no horizontal rules appear inside the mechanics frame. The rail does the work of segmentation, letting body text breathe.
